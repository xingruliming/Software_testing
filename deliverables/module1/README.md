# 模块一交付件说明

本目录中的 Excel 和 Word 文件是根据课程附录建立的待填报副本，不包含 AI 生成的计分测试用例、测试执行结果或缺陷结论。

文件用途：

- `VGGT模块一测试用例清单_待人工填写.xlsx`：附录1副本，仅填写基本项目信息；具体用例由小组人工补充。
- `VGGT模块一缺陷报告_待人工填写.doc`：附录2副本；只记录真实复现的缺陷。
- `VGGT模块一测试报告_待人工填写.docx`：附录3副本；结果、缺陷和贡献度在人工测试后填写。
- `测试操作手册.md` / `测试操作手册.docx`：内容一致的维护版和提交版。
- `交付检查清单.md`：提交前逐项核对。

模板中的姓名、学号、日期、贡献比例、用例数、执行数据和缺陷信息均需由小组成员据实填写。
