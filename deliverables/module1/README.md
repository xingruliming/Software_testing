# 模块一交付件说明

本目录中的 Excel 和 Word 文件根据课程附录建立。教师后来已明确许可 AI 参与模块一用例设计；Excel 已录入 32 条坐标转换测试用例，但不包含虚构的执行结果或缺陷结论。

文件用途：

- `VGGT模块一测试用例清单_待人工填写.xlsx`：附录1填报版，已包含 32 条用例；实际结果和状态须测试执行后填写。
- `VGGT模块一缺陷报告_待人工填写.doc`：附录2副本；只记录真实复现的缺陷。
- `VGGT模块一测试报告_待人工填写.docx`：附录3副本；结果、缺陷和贡献度在人工测试后填写。
- `测试操作手册.md` / `测试操作手册.docx`：内容一致的维护版和提交版。
- `交付检查清单.md`：提交前逐项核对。

模板中的姓名、学号、日期、贡献比例、执行数据和缺陷信息仍需由小组成员据实填写。
