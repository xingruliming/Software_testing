# 模块一人工测试工程接入说明

本目录预留给模块一 pytest 测试代码。教师后来已明确许可 AI 参与用例设计，附录1现有 32 条可自动化用例；本目录目前仍未实现对应 pytest 代码。

人工实现时应满足：

- 被测范围与测试报告一致，默认聚焦 `vggt-main/vggt/utils/geometry.py`；
- 按附录1中的 `M1-GEO-001` 至 `M1-GEO-032` 建立同编号测试，自动化实现不少于 24 条；
- 至少使用等价类、边界值、场景法中的两种方法；
- 测试编号与附录1 Excel、执行日志和缺陷报告可追溯；
- 测试不得依赖导入 `demo_gradio_cn.py`，因为该脚本导入时会加载模型并启动 Gradio；
- 测试工程应从外层配置 `vggt-main` 的导入路径，不为可测性随意修改被测源码；
- 统一由后续创建的根目录 `run_tests.ps1` 执行，并将结果写入 `test_results/module1/`。

不得将“测试未通过”等同于有效缺陷。有效缺陷必须经过复现、分析、处理和复测，并在缺陷报告中留下证据。
